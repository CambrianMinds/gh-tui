Core Features

📊

Repository Dashboard

Instantly view the README and current status of your target repository natively in the terminal.

🔐

Interactive Login

Seamlessly authenticate with GitHub using the official CLI auth flow without leaving the TUI.

⚙️

Remote Management

Add, remove, and manage your local git remotes and default GitHub repositories from a dedicated configuration panel.

📝

Issues & Pull Requests

Browse open tickets in an interactive data table, read full Markdown descriptions, and jump directly to the browser.

Quick Start

Ensure you have Python 3.10+ and the GitHub CLI (gh) installed.

git clone https://github.com/cambrianminds/gh-tui.git
cd gh-tui
python -m venv venv
source venv/bin/activate  # On Windows: .\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
