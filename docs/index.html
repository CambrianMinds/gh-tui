Get Started

Ensure you have Python 3.10+ and the GitHub CLI (gh) installed.

One-line Installation (Windows PowerShell)
irm https://raw.githubusercontent.com/cambrianminds/gh-tui/main/install.ps1 | iex
Manual Installation (Cross-Platform)
git clone https://github.com/cambrianminds/gh-tui.git cd gh-tui python -m venv venv source venv/bin/activate # On Windows: .\venv\Scripts\Activate.ps1 pip install -r requirements.txt python app.py
